# نوشتن، فرمت و بازخوانی

## نوشتن
1. `get_spreadsheet` برای نام واقعی تب‌ها (نام تب‌ها عوض می‌شود؛ مثلاً g2 → comments).
2. آخرین ردیف پر را بخوان؛ ستون Review Date بازه جدید را TEXT کن.
3. فقط `update_values` با رنج صریح، دسته‌های ≤ ۲۰ ردیف. هرگز `append_values` (یک بار ردیف‌ها را در ردیف ۱۰۱ درج کرد).

## فرمت ردیف‌های جدید (batchUpdate، fieldها نقطه‌ای: `userEnteredFormat.wrapStrategy` …)
- wrap + vertical TOP + فونت ۱۰ برای همه ستون‌ها
- ستون خلاصه فارسی: راست‌چین + RTL
- ستون امتیاز: NUMBER `0.0` + وسط‌چین
- ستون اول و ستون Software: bold
- حاشیه SOLID دور و داخل
- `setBasicFilter` تا آخرین ردیف
- `autoResizeDimensions` برای ردیف‌های جدید

## بازخوانی
ردیف آخرِ قبلی دست‌نخورده؛ ردیف‌های جدید پر؛ ردیف بعد از آخر خالی؛ تاریخ‌ها متن؛ Software/Source درست؛ تب‌های دیگر دست‌نخورده. شمارش‌ها از JSON خودم (`verify_rows.py`)، نه از حافظه.
